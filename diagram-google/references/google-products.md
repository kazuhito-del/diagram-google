## 効果的な検索クエリ

### 最新アップデートを調べるとき

```
Google [製品名] new features [年] site:blog.google
Google [製品名] update [年] site:workspace.google.com/blog
[製品名] 新機能 [年] site:japan.googleblog.com
```

### 具体的な使い方を調べるとき

```
how to use [機能名] Google [製品名]
[機能名] Google [製品名] tutorial
[製品名] [機能名] 使い方
```

### フリーランス・ビジネス活用を調べるとき

```

[製品名] 活用 フリーランス
```

## 情報収集のコツ

### 最新情報を見逃さない

- Google公式ブログはRSSやメールマガジンで購読できる
- 「Google Workspace Updates」で検索するとまとめて新機能が確認できる
- YouTubeでは「Google Workspace」公式チャンネルに動画がある

### 情報の鮮度を確認する

図解を作る前に必ず確認:
- その機能はいつ発表・リリースされたか
- 現在も有効か（廃止・変更されていないか）
- 日本でも使えるか（地域制限があるか）

### フリーランスとして特に注目すべき機能カテゴリ

1. **AI自動化**: 繰り返し作業を短縮できる機能
2. **コミュニケーション効率化**: メール・ミーティング・チャット系
3. **ドキュメント生成**: 提案書・報告書・議事録の自動作成
4. **検索・リサーチ**: 情報収集を高速化する検索機能
5. **広告・マーケティング**: Google広告・Analytics の新機能

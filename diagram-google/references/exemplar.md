# 模範解答パターン

## 成功する図解の構造

構成の制約（セクション数・ステップ数など）→ SKILL.md の「制約」セクションを参照。

```
1. ヘッダー（Googleカラーグラデーション背景）
   └─ 機能名 + 製品バッジ + 発表日

2. 一言サマリーカード（ヒーロー）
   └─ 「これで何ができるようになった？」1文
   └─ ビフォーアフター対比（赤カード vs 緑カード）
   └─ 利用条件バッジ（対象プラン・地域）

3. 今すぐ試せる手順（必須）
   └─ 番号付きステップ（Googleカラーで色分け）
   └─ 各ステップに操作の説明（1〜2行）

4. フリーランス活用ポイント + 出典（最後のカード）
   └─ 具体的なユースケース
   └─ 注意点・制限事項（箇条書き）
   └─ 公式ブログ・ヘルプセンターへの出典リンク
```

## ビフォーアフターの書き方

変化を一目で伝えるために、必ず対比形式にする。

```html
<div class="grid md:grid-cols-2 gap-4">
  <!-- 変更前（赤） -->
  <div class="bg-red-50 border border-red-200 rounded-xl p-4">
    <div class="flex items-center gap-2 mb-2">
      <i data-lucide="x-circle" class="w-4 h-4 text-red-500"></i>
      <span class="text-sm font-bold text-red-700">今まで</span>
    </div>
    <p class="text-gray-700 text-sm">【以前の状態を具体的に】</p>
  </div>

  <!-- 変更後（緑） -->
  <div class="bg-green-50 border border-green-200 rounded-xl p-4">
    <div class="flex items-center gap-2 mb-2">
      <i data-lucide="check-circle" class="w-4 h-4 text-green-500"></i>
      <span class="text-sm font-bold text-green-700">これから</span>
    </div>
    <p class="text-gray-700 text-sm">【新しい状態を具体的に】</p>
  </div>
</div>
```

## 手順ステップの色パターン

4ステップ以内ならGoogleカラーを1色ずつ使う。

```
ステップ1 → Google Blue (#4285F4)
ステップ2 → Google Green (#34A853)
ステップ3 → Google Yellow (#FBBC05)
ステップ4 → Google Red (#EA4335)
ステップ5以降 → 繰り返し or グレー (#6B7280)
```

## フリーランス活用カードの書き方

AIフリーランスとして具体的にどう使うかをカード形式で示す。

```html
<div class="grid gap-4">
  <div class="border border-gray-200 rounded-xl p-4">
    <div class="flex items-start gap-3">
      <i data-lucide="[関連アイコン]" class="w-5 h-5 text-blue-500 flex-shrink-0 mt-0.5"></i>
      <div>
        <p class="font-semibold text-gray-800">【活用シーン名】</p>
        <p class="text-sm text-gray-600 mt-1">
          【具体的な使い方と効果。「〜することで〜が〜になる」の形で書く】
        </p>
      </div>
    </div>
  </div>
</div>
```

## よくある失敗パターンと修正

### ❌ 「知る」で終わっている

```
❌ 「このような機能が追加されました。ぜひ活用してみてください。」
✅ 「Gmail → 作成ボタン → Geminiアイコンの順にクリックするとすぐ使えます。」
```

手順が書かれていない図解は、読んでもすぐに使えない。必ず「今すぐ試せる手順」を含める。

### ❌ 利用条件が不明

```
❌ 「この機能はすべてのユーザーが使えます。」（曖昧）
✅ 「Google Workspace Business Starter以上が必要。個人Gmailでは使えません。」（具体的）
```

フリーランスとして使えるかどうかが一目でわかるように条件を明記する。

### ❌ フリーランス視点がない

```
❌ 「ビジネスの生産性向上に役立ちます。」（漠然としている）
✅ 「提案書の下書き作成時間が10分→2分になる。月20本の提案ならひと月2.7時間の節約。」（具体的な数字と状況）
```

AIフリーランスとして収入を得るために「この機能がどう役立つか」を具体的に書く。

### ❌ 古い情報が混じっている

```
❌ WebSearchなしで「Geminiは〇〇ができます」と書く（学習データが古い可能性）
✅ 必ずWebSearchで最新情報を確認してから「発表日: 〇年〇月」と書く
```

## 品質チェックリスト

構成の数値制約（セクション数・ステップ数など）→ SKILL.md の「制約」セクションで確認。

### コンテンツ
- [ ] 「これで何ができるようになった？」が1文で書かれている
- [ ] ビフォーアフターが対比形式で書かれている
- [ ] 「今すぐ試せる手順」が番号付きステップで書かれている
- [ ] フリーランス活用ポイントがある
- [ ] 利用条件（対象プラン・地域）が明記されている
- [ ] 発表日・リリース日が載っている
- [ ] 出典リンクが載っている
- [ ] 最新情報をWebで確認した（古い情報を使っていない）

### デザイン
- [ ] Lucide iconを使用（絵文字禁止）
- [ ] Googleカラー（青・赤・黄・緑）が使われている
- [ ] スマホでも読みやすい（レスポンシブ）
- [ ] 文字サイズが読みやすい（本文は `text-sm` 以上）
